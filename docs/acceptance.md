# 验收清单

每个阶段结束后逐条打勾。任一条不通过就不进入下一阶段——地图错了，后面调参全是白费。

## 阶段 1 · 建模

- [ ] `check_urdf` 通过，无 warning
- [ ] RViz 中 TF 树为 `base_footprint → base_link → {left_wheel, right_wheel, caster, laser_link}`
- [ ] 拖动 joint slider，左右轮转向相反且与前进方向一致
- [ ] 车体不悬空、不陷地（`base_footprint` 高度 = 轮半径）
- [ ] 每个 link 都有 `inertial`，质量与惯性张量非零
- [ ] `collision` 为简化几何体，未复用高精度 mesh

## 阶段 2 · 仿真

- [ ] gz sim 启动无插件报错
- [ ] 键盘遥控可前进 / 后退 / 原地转
- [ ] `/scan` `/odom` `/tf` `/clock` 均有数据，频率符合预期
- [ ] 四条话题时间戳均为仿真时间（非 0、非墙钟）
- [ ] `tf2_echo odom base_footprint` 位移与视觉一致（推 1 m 报 1 m）
- [ ] RViz 中 scan 贴合墙面，不穿墙

## 阶段 3 · 建图

- [ ] 地图墙体连贯，无重影双墙
- [ ] 门洞两侧墙面不粘连
- [ ] 墙体厚度 ≤ 2 层栅格
- [ ] 地图尺寸与实际场景误差 < 5%
- [ ] `map.pgm` / `map.yaml` 已入库，`resolution: 0.05`

## 阶段 4 · 导航

- [ ] AMCL 从给定初始位姿收敛 < 3 s
- [ ] 静止时定位误差 < 0.1 m / 2°
- [ ] 全局路径不穿墙、不贴墙
- [ ] 10 个随机目标点 ≥ 8 个成功
- [ ] 平均单任务耗时 < 40 s，全程无碰撞
- [ ] 卡住时能观察到 recovery（后退 / 旋转）后继续
- [ ] 窄门（1 m 宽）可通过，不出现门前反复进退

## 阶段 5 · 调优与评测

- [ ] 批量评测脚本产出 CSV，字段完整
- [ ] 有基线数据表（成功率 / 耗时 / 路径效率 / 最小间距）
- [ ] 参数敏感性曲线至少 1 张（成功率 vs 最大速度）
- [ ] 自研插件与默认算法在同一组目标上对比完成
- [ ] 结论写明优劣，不只贴数据

## 阶段 6 · 真机（可选）

- [ ] gz 插件替换为 `ros2_control` + `diff_drive_controller`
- [ ] 真实传感器发布 `LaserScan` / `Odometry` / `tf`
- [ ] `robot_localization` 完成轮式 + IMU 融合
- [ ] 一键启动 README、架构图、参数说明、演示视频齐备
